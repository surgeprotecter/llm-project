Python 后端连接与 MCP 桥接配置

将此可视化前端无缝接入你的本地 nlp-project/src/travel_agent

接口约定（已实现在 src/travel_agent/server.py） 
# 启动桥接服务（项目根目录）
uv run uvicorn travel_agent.server:app --reload --port 8000

# 调用：session_id 即 LangGraph thread_id，多轮共享同一 checkpoint
curl -X POST http://localhost:8000/api/chat \
  -H 'Content-Type: application/json' \
  -d '{"message":"帮我做一份东京5天的行程","session_id":"demo-1","real_only":false}'

# 返回
{"reply": "...", "status": "completed",
 "session_id": "demo-1", "plan": null,
 "traces": [{"tool": "itinerary_step", "action": "...", "result": "...", "latency": "1.2s"}],
 "report": {"version": 1, "html_path": "output/...", "markdown_path": "output/...",
            "created_at": "..."}}

健康检查：GET /api/health；real_only=true 等价于 CLI 的 --real-only。
